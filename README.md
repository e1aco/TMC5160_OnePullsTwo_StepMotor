# TMC5160 步进电机驱动器

基于 STM32H750 + TMC5160 的高性能闭环步进电机驱动器，支持双电机独立控制，通过 CAN 总线通信。

## 项目状态

- ✅ 硬件验证完成（SPI 模式）
- ✅ CAN 通信协议实现
- ✅ 闭环控制（编码器反馈 + 补步）
- ✅ 散热优化：3A 持续运行温度 ≤ 70℃

## 硬件规格

| 参数 | 规格 |
|:-----|:-----|
| 主控芯片 | STM32H750VBT6（注：建议改用 STM32F103 系列） |
| 驱动芯片 | TMC5160 |
| 电机型号 | 57CME13 闭环步进电机 |
| 驱动模式 | SPI 模式（SD_MODE=0, SPI_MODE=1） |
| 采样电阻 | 0.05Ω / 1W |
| MOS 管 | AOD4126 |
| 时钟频率 | 14MHz（TMC_CLK） |
| SPI 频率 | ≤8MHz（TMC5160 最高 16/2=8MHz） |
| 通信接口 | CAN FD |
| 驱动电流 | 最大 3A（持续运行温度 ≤ 70℃） |

> **主控选型建议**：TMC5160 驱动芯片最高时钟 16MHz，SPI 最高 8MHz，无需使用 STM32H750 这类高性能芯片。建议改用 **STM32F103** 系列（如 STM32F103C8T6），成本更低且完全满足需求。当前使用 H750 属历史遗留原因。

## 软件特性

- **SPI 完全控制**：通过 SPI 接口配置 TMC5160 所有参数
- **双电机支持**：可独立控制两个电机（U1/U2）
- **多种运动模式**：
  - 绝对位置定位
  - 相对位置移动（正转/反转）
  - 速度模式持续旋转
  - 停止/刹车
- **闭环控制**：编码器反馈 + PID 补步（预留）
- **运动参数组**：预定义 4 组运动参数（低速精准/中速普通/快速/高速）
- **PID 在线调参**：支持通过 CAN 实时调整 PID 参数
- **状态反馈**：实时上报位置、状态标志、运动阶段

## CAN 通信协议

### 1. 接收命令协议 (CAN ID: `0x1AA55F42`)

| 字节索引 | 含义 | 说明 |
|:--------|:-----|:-----|
| [0-3] | 值 (int32) | 4字节小端（低字节在前），含义由命令码决定 |
| [4] | 命令码 | 见下方命令码表 |
| [5] | 电机选择 | 0x01=U1, 0x02=U2, 0x06=所有电机 |
| [6] | 参数/分组 | 0x01~0x04=运动参数组（命令0x01~0x05），0x01~0x06=PID参数类型（命令0x06） |
| [7] | 校验和 | 前7字节累加取低8位 |

#### 命令码定义

| 命令码 | 名称 | [0-3] 含义 | [6] 含义 |
|:------:|:-----|:-----------|:---------|
| 0x01 | 绝对位置移动 | 目标位置（微步） | 运动参数组 (0x01~0x04) |
| 0x02 | 相对位置正转 | 移动步数 | 运动参数组 (0x01~0x04) |
| 0x03 | 相对位置反转 | 移动步数 | 运动参数组 (0x01~0x04) |
| 0x04 | 速度模式 | 目标速度（微步/秒） | 运动参数组 (0x01~0x04) |
| 0x05 | 停止/刹车 | 0（忽略） | 运动参数组 (0x01~0x04) |
| 0x06 | PID调参 | 参数值（Q16或整数） | PID参数类型 (0x01~0x06) |

#### 运动参数组定义 (命令 0x01~0x05 使用)

| 参数组 | 说明 | VMAX | AMAX | 典型场景 |
|:------:|:-----|-----:|-----:|:---------|
| 0x01 | 低速精准 | 5,000 | 1,000 | 精准定位 |
| 0x02 | 中速普通 | 20,000 | 5,000 | 日常运动 |
| 0x03 | 快速 | 50,000 | 10,000 | 快速移动 |
| 0x04 | 高速 | 100,000 | 20,000 | 长距离搬运 |

#### PID参数类型定义 (命令 0x06 使用)

| 参数类型 | 含义 | 值格式 | 默认值 |
|:--------:|:-----|:-------|-------:|
| 0x01 | Kp（比例系数） | Q16定点数 | 8192 (0.5) |
| 0x02 | Ki（积分系数） | Q16定点数 | 2048 (0.125) |
| 0x03 | Kd（微分系数） | Q16定点数 | 4096 (0.25) |
| 0x04 | out_max（最大输出速度） | 直接整数 | 50000 |
| 0x05 | out_min（最小输出速度） | 直接整数 | -50000 |
| 0x06 | integral_max（积分限幅） | 直接整数 | 32768 |

> **Q16定点数**：实际值 = Q16值 / 65536。例如 Kp=0.5 → Q16值 = 0.5 × 65536 = 8192。

### 2. 反馈响应协议 (CAN ID: `0x1AA55F43`)

| 字节索引 | 含义 | 说明 |
|:--------|:-----|:-----|
| [0-3] | 值 (int32) | 4字节小端，含义由 byte[6] 决定 |
| [4] | 标志/参数类型 | 运动反馈=状态标志位，调参反馈=参数类型 |
| [5] | 电机选择 | 0x01=U1, 0x02=U2 |
| [6] | 反馈类型 | 0x01~0x05=运动反馈，0x06=调参反馈 |
| [7] | 校验和 | 前7字节累加取低8位 |

#### 运动反馈 (byte[6] = 0x01~0x05)

| 字节索引 | 含义 | 说明 |
|:--------|:-----|:-----|
| [0-3] | 位置值 (int32) | 当前电机 XACTUAL 绝对位置 |
| [4] | 状态标志位 | bit0=到位, bit1=堵转, bit2=过温, bit3=驱动错误, bit4=SPI异常 |
| [5] | 电机选择 | |
| [6] | 运动阶段 | bit0=加速, bit1=匀速, bit2=减速, bit3=归零等待, bit4=静止锁轴 |
| [7] | 校验和 | |

**状态标志位 (byte[4]) 详解：**
```
bit0 → 0=运动中，1=已到位
bit1 → 0=正常，1=堵转/失步
bit2 → 0=正常，1=过温告警
bit3 → 0=正常，1=驱动错误
bit4 → 0=SPI正常，1=SPI通讯异常
bit5-7 → 保留
```

#### 调参反馈 (byte[6] = 0x06)

| 字节索引 | 含义 | 说明 |
|:--------|:-----|:-----|
| [0-3] | 参数值 (int32) | 刚设置的参数值 |
| [4] | 参数类型 | 0x01=Kp, 0x02=Ki, 0x03=Kd, 0x04=out_max, 0x05=out_min, 0x06=integral_max |
| [5] | 电机选择 | |
| [6] | 固定 0x06 | 标识为调参反馈 |
| [7] | 校验和 | |

#### 反馈发送规则

| 命令码 | 发送时机 |
|:------:|:---------|
| 0x01/0x02/0x03 | 立即发送启动反馈 + 到位后发送到位反馈 |
| 0x04/0x05 | 仅立即发送一次 |
| 0x06 | 立即发送调参确认反馈 |
| 异常 | 堵转/过温/驱动错误/SPI异常状态变化时，5ms定时器触发发送 |

## 构建说明

### 环境要求

- CMake 3.20+
- ARM GCC 工具链 (`arm-none-eabi-gcc`)
- STM32CubeMX（可选，用于重新生成初始化代码）

### 编译步骤

```bash
cd Firmware/TMC5160H7Cmake_StepMotor

# 使用 CMake Presets 配置（推荐）
cmake --preset gcc-arm-none-eabi
cmake --build build

# 或手动配置
mkdir build && cd build
cmake -DCMAKE_TOOLCHAIN_FILE=../cmake/gcc-arm-none-eabi.cmake ..
make -j4
```

### 烧录

- 使用 STM32CubeProgrammer 通过 SWD 烧录
- 或使用 J-Link：`JLinkExe -device STM32H750VBTx -if SWD -speed 4000`

## 理论参考

### 1. 原理图设计要点

1. **电源设计**：VSA 与 VS 由一路供电时最安全；若 VS 超过 24V，VSA 应使用单独的开关电源
2. **MOS 管选型**：
   - 选择适合电机电压（峰值+5~10V余量）和最大电流的 MOSFET
   - Vth 选择 10V 以内（TMC5160 驱动电压约 10V）
   - 根据米勒电荷选择栅极电阻（AOD4126: 10nC → 10Ω 栅极电阻）
3. **保护电路**：BM 引脚到地建议添加 TVS 二极管，避免低于 -5V 的峰值

### 2. PCB 布线要点

1. 采样电阻和滤波电容尽可能靠近功率 MOSFET
2. TMC5160 靠近 MOSFET 放置，短线互连
3. 所有 GND、GNDA、GNDD 连成公共地
4. 做好芯片散热（内部 LDO 功耗较大）
5. MOSFET 栅极走线短而直、较宽

### 3. TMC5160 配置

- **SPI 模式**：CPOL=1, CPHA=1（模式 3）
- **数据帧**：40 位（5 字节），CS 片选定界
- **时钟配置**：14MHz 方波（84MHz / 6 = 14MHz）
