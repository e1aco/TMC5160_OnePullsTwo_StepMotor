# 附录 A: CAN 命令协议 — 来源: 用户协议 v2.1（v2 2026-09-24 确认稿 + 2026-09-30 追加 0x09 读位置/到位帧状态位/急停全关）
> 收发模型：经典帧 / 扩展 ID / 8 字节 / 500kbit/s；硬件过滤器只收命令 ID 进 RX FIFO0，其余丢弃；
> 中断入队 → 任务A `CAN_CMD_Process()` 逐条分发（实现见 module/app/can_cmd.c）。
> 校验和：byte7 = (byte0+…+byte6) & 0xFF（收发同算法，不符的帧丢弃）。

## 命令帧 0x1AA55F42 (上位机 → MCU)

| byte | 字段 | 说明 |
| :--- | :--- | :--- |
| 0 | cmd | 命令码 0x01~0x09（见下表） |
| 1 | motor | 电机位号：位掩码，bit(i)=电机 i+1（0x01=电机1，0x02=电机2，0x03=电机1+2，…，最大 0x1F=5 台）；0x00 或含 5 位外无效位 → 非法掩码 |
| 2 | param | 运动参数组 0x01~0x06（仅 0x01~0x04 用；速度依次提高，0x06 最快） |
| 3-6 | value | 32 位整数，**大端**：值 = Can[3]<<24\|Can[4]<<16\|Can[5]<<8\|Can[6]；标志类命令取 0x00000000/0x000000FF（仅 Can[6]=0x00/0xFF） |
| 7 | checksum | 见上 |

| cmd | 名称 | value 含义 | 执行动作 | 反馈时机 |
| :--- | :--- | :--- | :--- | :--- |
| 0x01 | 绝对定位 | 目标绝对位置 µsteps | 按 param 组运动到 value | ACK + 到位后补到位反馈 |
| 0x02 | 相对正转 | 偏移量 µsteps（正） | 从当前位置 +value | 同上 |
| 0x03 | 相对反转 | 偏移量 µsteps（负） | 从当前位置 −value | 同上 |
| 0x04 | 速度模式 | 0x00=正转，0xFF=反转（方向）；速度取 param 组档位 | 持续旋转 | 仅即时 ACK（无终态） |
| 0x05 | 回零 | 0x00=负向寻零，0xFF=正向寻零（方向）；速度固定 2RPS | StallGuard2 碰限位回零（异步） | 启动成功回 ACK，**完成时再发到位反馈** |
| 0x06 | 闭环使能/失能 | 0x00=使能，0xFF=失能 | 使能/禁用该电机闭环 | ACK + 完成发到位反馈 |
| 0x07 | 停止/急停 | 0x00=停止，0xFF=急停 | 停止切定位锁轴；急停拉高 ENN 关功率级自由停车 | ACK + 完成后发到位反馈 |
| 0x08 | 在线清零 | 0x00（固定） | 停稳后 XACTUAL/X_ENC 写 0（长时单向 soak 越限前重建基线） | ACK + 补到位反馈 |
| 0x09 | 读位置 | Can[2]=位置源：0x00=XACTUAL(指令位置,默认)/0x01=X_ENC(编码器计数) | 只读诊断：单读所选寄存器，掩码内每电机回一帧**位置反馈** | 位置帧（ACK + 各自位置帧） |

> 命令码不在 0x01~0x09 → 回错误码 0xE4（未知命令）。
>
> 电机掩码校验：0x00 或含 5 位外无效位 → 回错误码 0xE3（非法电机掩码），命令不执行。
>
> cmd 0x05 回零语义：掩码内多电机并发回零（同向）；忙中（任一所选电机回零中）→ 回 0xE2，不打断；方向由 value（0x00 负 / 0xFF 正）；速度固定 2RPS；终态到位反馈到位=0x01。回零失败/超时/被打断/急停 → 置未校准。
>
> cmd 0x07 急停语义（value=0xFF）：参数/电机掩码一律忽略——**无视 Can[1]（0x00/越界/任意值均执行），关闭全部电机功率级**（拉高 ENN 自由停车）；置未校准，反馈回 0xE1；再运动前须 0x05 重回零。value=0x00 为一般停止（仅停掩码内电机、锁轴，回 ACK）。
>
> cmd 0x08 在线清零语义：上位机须先发 0x07（value=0x00）停稳再发本命令；清零后位置/命令目标归 0，后续相对运动基准即新零点；回零机忙（校准中）时按门控拒绝。
>
> cmd 0x09 读位置语义：诊断只读、**豁免校准门控**（急停置未校准后仍可取证）；Can[2]=位置源（0x00=XACTUAL 指令/0x01=X_ENC 编码器，其余值按 XACTUAL）；Can[1]=电机掩码；Can[3..6] 忽略（checksum 照常）；掩码内每电机一帧位置反馈（不等待齐）。
>
> 校准门控（实现约定）：上电电机为未校准 → 除 0x05 外任何命令回 0xE1；回零进行中 → 0x05 忙拒回 0xE2，其他任何命令打断回零（置未校准）并回 0xE2；回零成功 → 已校准；0x07 急停始终执行（在掩码校验/门控之前全局拦截）、0x09 只读豁免。

## 反馈帧 0x1AA55F43 (MCU → 上位机)

### 及时反馈（ACK）：命令有效、已开始执行

| byte | 字段 | 说明 |
| :--- | :--- | :--- |
| 0 | cmd | 回显收到的命令码 |
| 1-6 | 0 | 固定 0x00 |
| 7 | checksum | 见上 |

示例（收到命令码 0x01）：`01 00 00 00 00 00 00 01`。

### 到位反馈：电机运行到位 / 操作完成（无位置值）

| byte | 字段 | 说明 |
| :--- | :--- | :--- |
| 0 | cmd | 回显命令码 |
| 1 | motor | 单电机位号（多电机命令每台各发一帧，不等待齐） |
| 2 | param | 回显运动参数组 |
| 3 | 到位标志 | 0x01=到位 / 0x00=到位失败 |
| 4 | 过温警报 | 0x01=过温（>120℃）/ 0x00=正常 |
| 5 | 驱动器异常 | 0x01=异常 / 0x00=正常 |
| 6 | 状态位 | 组合位（v2.1）：bit0 到位 / bit1 失步（ENC_STATUS.deviation_warn）/ bit2 过温（DRVSTATUS ot+otpw）/ bit3 驱动错（GSTAT.drv_err）/ bit4 SPI 通讯异常（任一寄存器读到 0xFFFFFFFF 哨兵） |
| 7 | checksum | 见上 |

适用：0x01/0x02/0x03/0x05（回零完成发 0x01）/0x06（完成发 0x01）/0x07/0x08；0x04 速度模式无终态。失败同样发本帧，到位标志置 0x00。

### 位置反馈：0x09 读位置（含位置值，v2.1）

| byte | 字段 | 说明 |
| :--- | :--- | :--- |
| 0 | cmd | 回显命令码 0x09 |
| 1 | motor | 单电机位号（每台各发一帧，不等待齐） |
| 2 | 状态位 | 仅 bit4 = SPI 通讯异常（该次 XACTUAL 读为 0xFFFFFFFF 哨兵时置位，位置值不可信）；其余位固定 0 |
| 3-6 | 位置 | XACTUAL，int32 **大端**：值 = Can[3]<<24\|Can[4]<<16\|Can[5]<<8\|Can[6]（µsteps） |
| 7 | checksum | 见上 |

> 0x09 每电机仅 1 次 SPI 读（XACTUAL 或 X_ENC，由请求 Can[2] 选）；状态位只反映该次读的通讯有效性；失步/过温/驱动错由 0x01~0x08 的到位帧（byte6）携带。X_ENC 与 XACTUAL 实测同量纲（ΔENC/ΔACT≈0.999，2026-09-30 标定），可直接与 µsteps 目标比较。

### 错误码反馈

| byte | 字段 | 说明 |
| :--- | :--- | :--- |
| 0-6 | 错误码 | Can[0..6] 全部填同一个错误码 |
| 7 | checksum | 见上 |

| 错误码 | 名称 | 含义 |
| :--- | :--- | :--- |
| 0xE1 | 未校准 | 位置基准丢失，须重新回零 |
| 0xE2 | 正在校准中 | 回零进行中 |
| 0xE3 | 非法电机掩码 | 电机位号为 0 或含无效位 |
| 0xE4 | 未知命令 | 命令码不在 0x01~0x09 |

> 反馈时机：运动类命令（0x01/0x02/0x03）先回 ACK，到位后发到位反馈；30s 未到也发一帧当时状态（上位机判超时）；
> 速度模式（0x04）无终态；回零（0x05）ACK + 到位双帧。

# 附录 B: 工作流程 (项目意图)
- 两路电机分别回零（无编码器 StallGuard2 回零，SPI 轮询判完成）；一路到位后 CAN 控制第二路回零；完成后上报
- 回零完成后接受相对/绝对/速度运动指令；所有模式限制在 [0, 最大目标值] 内，越界上报（防堵转/不可控）
- 两电机位置互不干涉的仲裁方式待定（上位机 or MCU）
- 功能轮子: ①上电回零（速度+方向→堵转确认零点→反向几微步防卡死→置零）②相对/绝对/速度模式（已有）③堵转/过流保护（运行中堵转立即停+反向几步）④梯形/线性规划（已有，待评估 S 型）⑤闭环位置控制（已有，待调）⑥CAN 通讯（已有，协议待完善）⑦SPI 读写 TMC5160（已有，寄存器级实测 9.2/23.6us）
